Entry for the make.fun bounty **[Sum up 17 November's world news in one image](https://make.fun/bounty/news-image-20261117)**.

A Python program that draws a single 1024×1024 newspaper-style front page covering the major world stories of Tuesday 17 November 2026 (Kerch Bridge strike, Iran–Bahrain, Trump Asia trip / trilateral, EU Rwanda return hub, digital outages, and more).

## Run

```bash
python main.py
# writes /output/entry.png
```

Requires Pillow.
